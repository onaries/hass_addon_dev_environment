# Home Assistant SSH and Docker add-on

This repository provides SSH access and the Docker CLI for Home Assistant.

Add `https://github.com/onaries/hass_addon_dev_environment` to the Home Assistant app store, install **Python Development Environment**, configure SSH credentials, and start it. Docker access requires the add-on's Docker API access and protection mode to be disabled.

The existing add-on slug and image name are retained for upgrades. See [the add-on documentation](python_dev_env/README.md).
